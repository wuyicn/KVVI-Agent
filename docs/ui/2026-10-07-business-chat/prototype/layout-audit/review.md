# 搭建者与员工布局评审

范围：本地7505 UI原型的布局、操作入口和角色一致性。未修改原型代码或正式产品。

## 当前证据

1. 搭建者页面：01-builder.jpg。业务上下文、表单字段编辑和会话反馈明确；会话在中间、表单在右侧，两栏接近等宽，复杂表单容易受限。
2. 员工页面：02-employee.jpg。表单为主要区域，助手在右侧，提交入口明确；重复说明较多，助手固定展开且历史占据大块区域。

两张截图均在本轮直接从当前原型捕获并打开检查。当前宽屏截图为1661×1184；未以旧图替代证据。原型没有独立所有者视角，所有者部分仅为设计建议。

## 优点

- 左侧先选业务，表单和助手显示同一业务名称，上下文清楚。
- 直接改字段及会话修改结果结合良好，既可点击也可描述需求。
- 员工主区域保留业务操作和提交入口，助手提供直达表单或记录的按钮。

## 主要问题

- 切换搭建者和员工时，会话左右位置互换，需要重新寻找功能。
- 搭建者会话占据近半个工作区域，字段、流程或记录增加后业务空间不足。
- 业务标题、办理说明、卡片说明和确认提示重复；侧栏同时列出业务及会话历史，层级较多。
- 助手始终展开，手动办理时仍占空间；建议支持折叠和调整宽度。
- 铅笔编辑入口较小，建议保留可点击的整行字段标题并补充明确焦点样式；仅凭截图不能判断完整键盘或屏幕阅读器体验。

## 建议统一方案

统一为左侧业务导航、中间主要业务区、右侧可折叠的业务助手。不同角色保持区域位置，按授权任务展示操作；同一人可同时具备多个角色。

- 员工：办理表单、查看授权记录，助手帮助填写、查询和解释结果。
- 搭建者：在同一业务区进入配置模式，编辑表单、流程、试填及发布；助手负责配置该业务。
- 所有者：暂按业务负责人理解，以业务概览、授权范围内记录及管理入口为主，通过权限提供成员管理和配置入口。若指企业所有者，企业级管理放在企业设置中。

统一布局不扩大数据权限；搭建者和所有者均不自动获得全部业务记录权限。搭建、办理和管理仍使用各自任务与授权范围，助手随模式明确切换。

结论：当前布局适合验证业务和会话结合，但尚不宜冻结为最终布局；推荐统一页面骨架并让业务区域占主要空间。当前只评审，尚未实施此方案。
