## 二、部署基线与安全成立条件（PRD §4.6.5）

### 2.1 基线

> **本节列出的条件成立时，§4.6.5 的边界才成立。**

| # | 条件 | 本方案中的对应 |
|---|---|---|
| 1 | 两进程**分属不同容器或不同系统用户** | `docker-compose.kvvi.yml` 的 `platform` / `runtime` 两个 service |
| 2 | **禁止跨进程调试** | 不共享 pid/ipc namespace |
| 3 | **无共享可写文件系统** | 各自独立的 named volume，无共享挂载 |
| 4 | 两进程间接口**有调用方鉴别** | 受控端点要求 `KVVI_INTERNAL_TOKEN` |
| 5 | **平台服务进程不加载任何插件** | 镜像内没有 `@deepseek-ai/*`；可核验的启动配置 |
| 6 | **签名私钥仅存于签名进程** | 私钥由运行期挂载，不进镜像、不进仓库、不进日志 |

前四条在 compose 里成立；第五条由 `工具/check_topology.py` 与 `/topology` 端点复核；
第六条由「镜像内无私钥」的构建期约束保证。

### 2.2 ⚠️ 基线之外**不属于保证范围**

**明确不保证的情形**（读者不要把下面的部署当作满足基线）：

| 情形 | 为什么不保证 |
|---|---|
| 两进程部署在**同一容器**或同用户下 | 插件与身份判定同进程，「不加载插件」不再成立 |
| 挂载了**共享可写卷** | 重新开出一条进程间越权路径 |
| 开放了**跨进程调试** | 调试通道即任意读写 |
| 受控接口**未配置调用方鉴别** | 任何能到达该端口的进程都能调 |
| **私钥被放进镜像或仓库** | 签名私钥应仅存于签名进程；分发即泄漏 |
| 把三个库**合并成一个** | 「审计不可篡改」与「读权限独立」都只剩纪律 |

### 2.3 已确认的**固有边界**（不是待修缺陷）

> **已批准插件可冒用活跃会话的既有令牌。**
>
> 业务系统调用必须持有已签发的令牌，而运行时进程就是持有者；插件与该进程同进程，
> 可窃取任何活跃会话的短期令牌并直接调用业务系统。该令牌是真实权限、验签通过。
>
> **两进程划分消除的是「伪造与提权」，不是「冒用活跃会话」。**
> 其操作追溯已由红线 3 第二段排除。**交付时不得把这条写成「已解决」。**

## 三、验收证据包（PRD §7.1 阶段七）

```bash
python3 工具/验收证据包.py            # 跑各阶段判据并生成证据包
python3 工具/验收证据包.py --verify   # 复核证据文件与指纹
```

证据包位于 `交付/证据/`：`验收证据包.json` + 每个判据一份 `.txt`（输出**原样**保存）。

**设计上只做三件事：跑、原样存、记指纹。** 本工具**不做第二判定者** ——
如果它把各检查器的输出解析成自己的结论，两个判定者迟早不一致，
而不一致时无法判断该信谁。

> ⚠️ 各检查器输出末尾都有「本阶段未覆盖」一节，它**一并被收进证据文件**。
> 把「测过什么」与「没测什么」分开存放，会让后者在交付时消失。

## 四、干净环境部署（阶段七锚点①）

```bash
python3 工具/交付环境.py
```

它依次做六件事：确认部署对象就是被指纹覆盖的那一份 → 清掉同名项目与卷 →
`--build` 强制重建 → 等**健康检查**（不是「容器 Running」）→ 端到端探针 → 记证据。

## 五、交付时的诚实清单：**不主张**什么

| 不主张 | 依据 |
|---|---|
| 不主张**安全评审已完成** | 冻结记录 §「不主张什么」；§9.12 要求发布后由专门人员做正式威胁建模 |
| 不主张**契约层已验证完整** | 验证器自述 `semantic_validation_complete=false`、`runtime_verified=false`；三个契约**只有结构校验** |
| 不主张**模型输出稳定** | 黄金样例兑现的是「装配确定性」，不是「同一需求十次同一蓝图」 |
| 不主张**运行期行为符合配置** | 各检查器判定的是**配置**；运行期是否真按配置执行不在判定内 |
| 不主张**审计对插件运行期有效** | 完整性以「写入者不拦截审计」为前提；已作恶插件可拦截 |
| 不主张**访客可区分个体** | 追溯单位是签发人 + 链接 + 通道 |
| 不主张**部署面已满足 §4.6.1** | 三个库在同一实例上；逻辑隔离做到了，部署隔离没有 |
