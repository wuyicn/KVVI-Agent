# 看板生成（dashboard-builder）

看板回答的是**「业务现在怎么样」**。它不是一个把数据画成图的地方，
是一个让人**做出决定**的地方。每放一个图表都要能回答：看到它之后，人会做什么？

答不上来的图表，删掉。

## 何时用

- 用户要看汇总：*「做一个月度销售趋势看板」*
- 用户要看分布或对比：*「各个部门的完成情况」*
- `data-model` 定完模型后，为业务关心的读场景生成看板

## 前置

模型未定**先跑 `data-model`**。看板字段必须来自模型字段——
按界面需要临时造指标，会和约束、不变量对不上。

## 生成规范

### 1. 先定问题，再定图表

顺序不能反。先问：**这个看板要支持什么决定？**

| 业务问题 | 图表 |
|---|---|
| 趋势如何 | 折线图（时间是 X 轴） |
| 谁多谁少 | 横向条形图（按值排序） |
| 构成占比 | 堆叠条形或饼图（**仅当 ≤5 类**） |
| 与目标差距 | 进度条 / 仪表 |
| 单值状态 | 指标卡（大数字 + 对比） |
| 分布形态 | 直方图或箱线图 |
| 相关性 | 散点图 |
| 明细排查 | 表格（**不是图表**） |

**禁止**：用饼图表达超过 5 个分类；用 3D 或径向图；
用折线图画无序分类（折线意味着连续性，分类之间没有「之间」）。

### 2. 指标口径必须写明

每个指标要回答：

| 问题 | 例 |
|---|---|
| 分母是什么 | 「完成率 = 已完成 / 全部」，全部含不含已撤销？ |
| 时间口径 | 按创建时间还是完成时间？时区？ |
| 去重规则 | 一人多次提交算几次？ |
| 空值处理 | 无数据的部门是 0 还是不显示？**这俩看起来一样，含义完全不同** |
| 更新时机 | 实时 / 每小时 / 每天，以及数据延迟多久 |

口径没写清的指标**不要放进看板**——会被当成另一个口径用，导致会议上的数字打架。

### 3. 筛选器

看板必须有筛选器，且要**明确默认值**：

- 时间范围：默认最近 30 天（并允许自定义）
- 组织维度：默认当前用户可见范围，**不是全部**
- 状态：默认排除已撤销/已删除——否则数字虚高

筛选器的状态要能反映在 URL 或可分享的状态里，
否则用户无法把「我看到的那一屏」发给同事。

### 4. 权限

看板**继承数据权限，不能绕过**：

- 用户只能看到自己有权看到的行
- 聚合结果可能泄露明细：**小样本必须抑制**（如某组少于 N 人时不显示该组）
- 导出要单独授权——导出等于把明细带走

聚合不脱敏是看板最常见的越权泄露路径。

### 5. 布局

- 最重要的指标放**左上**（视线起点）
- 一屏不超过 4–6 个图表
- 指标卡在上（现在怎么样），趋势图在中（怎么变的），明细表在下（具体是谁）
- 每个图表有标题，标题说**问题**不说字段名：
  *「各部门完成率」*，不是 *「dept_completion_rate」*

## 输出格式

```yaml
看板: 月度销售趋势
服务的决定: 判断本月是否需要加大投放力度
筛选器:
  - { 名: 时间范围, 默认: 最近30天, 可自定义: 是 }
  - { 名: 组织, 默认: 当前用户可见范围 }
  - { 名: 状态, 默认: "排除已撤销" }
图表:
  - type: 指标卡
    标题: 本月销售额
    指标: { 聚合: sum, 字段: 金额, 口径: "按完成时间, 排除已撤销, 单位元" }
    对比: 上月同期
  - type: 折线图
    标题: 近30天销售趋势
    x: { 字段: 完成日期, 粒度: 天 }
    y: { 聚合: sum, 字段: 金额 }
    空值: 显示为0
  - type: 横向条形图
    标题: 各部门完成率
    维度: 部门
    值: { 聚合: "已完成/全部", 口径: "全部含进行中, 排除已撤销" }
    排序: 降序
    小样本抑制: "组内 <5 人时不显示"
  - type: 表格
    标题: 未完成申请明细
    字段: [申请号, 申请人, 部门, 金额, 状态, 停留时长]
    排序: 停留时长 降序
权限: { 继承: 数据权限, 导出: 需单独授权 }
```

## 常见错误

| 错误 | 后果 | 正确做法 |
|---|---|---|
| 先选图表再想问题 | 图表好看但无用 | 先定要支持的决定 |
| 饼图 12 个分类 | 无法比较 | 换横向条形图 |
| 口径未写明 | 会上数字打架 | 每个指标写全口径 |
| 空值当 0 | 误导为「有数据且为零」 | 区分并标注 |
| 默认含已撤销 | 数字虚高 | 默认排除 |
| 聚合不脱敏 | 越权泄露明细 | 小样本抑制 |
| 一屏 15 个图 | 没人看 | 一屏 4–6 个 |
| 标题用字段名 | 业务看不懂 | 标题说问题 |
